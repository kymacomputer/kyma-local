# Kyma Local v0.4.1

Import a saved Ironclad List All Records response or a review-table CSV with your local original documents.
Use the returned contract folder through the existing CLI or MCP workflow.

The importer preserves the export, document bytes, record identities, attachment links and missing-file context.
Source citations retain the original page or exact text span.
Your agent reads the original documents and resolves their scope and precedence.
The import command makes no network request and needs no API token.

This release also repairs JSON identities in revision events.
Changed decisions, conditions and drafts now retain exact equality at the SQLite receiver.
A partial local result can recover without a duplicate event.

See [Contract exports](../contract-imports.md) for the commands and the same-input native comparison.
Ironclad support covers one saved response page with explicit local attachment assignments.
The CSV schema is user-defined.
Native LinkSquares workbooks and proprietary Harvey or Legora exports remain separate formats.
